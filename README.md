# Potraviny Novák – Eshop

## Soubory
- `index.html` – zákaznická část (přihlášení, eshop, košík, stav objednávek)
- `admin.html` – admin panel (produkty, objednávky, zákazníci, provozovna)
- `manifest.json` – PWA (přidání na plochu telefonu)

## Demo přístupy
- Zákazník: `jan@firma.cz` / `heslo123`
- Admin: `admin@novak.cz` / `admin123`

## Jak nahrát na Vercel (zdarma, 5 minut)

1. Zaregistruj se na https://vercel.com
2. Klikni **Add New Project**
3. Přetáhni složku s těmito soubory
4. Klikni **Deploy**
5. Dostaneš URL jako `muj-eshop.vercel.app`
6. Otevři v mobilu → **Přidat na plochu**

## Jak nahrát na GitHub

1. Zaregistruj se na https://github.com
2. Klikni **New repository** → název např. `muj-eshop`
3. **uploading an existing file** → přetáhni soubory
4. Klikni **Commit changes**
5. V Vercelu: **Import Git Repository** → vyber repozitář → Deploy
